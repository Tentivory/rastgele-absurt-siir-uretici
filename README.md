# Rastgele Absürt Şiir Üretici

## Bu Nedir?

Bu repo, insanlık tarihinin en büyük buluşlarından biridir. Evrenin anlamını aramaktan yorulmuş, mantığı terk etmiş, sadece **rastgele kelimeleri bir araya getirerek** şiir üreten bir Python scriptidir.

**Çalışır.** Gerçekten çalışır. Her çalıştırdığınızda yeni, eşsiz, anlamsız ve müthiş şiirler üretir.

## Nasıl Çalıştırılır?

```bash
python siir_uretici.py
```

Çıktı örneği:

```
=== EVRENSEL ABSÜRT ŞİİR MAKİNESİ BAŞLATILDI ===
Lütfen bekleyin, şiirler uzaydan geliyor...

1. Banyo fil çaydanlık uzay kahve kediler...
2. Mantık yok evet hayır felsefe düşünce...
...
=== ŞİİR TAMAMLANDI. ANLAM ARAMAYIN. ===
```

## Neden Var?

Çünkü bazen şiir üretmek gerekir. Anlam şart değildir. Banyo yaparken felsefe yapmak gibi.

## Lisans

Herkes özgürce kullanabilir. Hatta fork'layıp daha da absürt hale getirebilirsiniz.
